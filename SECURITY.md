# Политика безопасности

## Поддерживаемые версии

| Версия  | Поддерживается |
| ------- | -------------- |
| 1.0.x   | ✅             |
| < 1.0   | ❌             |

## Сообщение об уязвимостях

Если вы обнаружили уязвимость в плагине, пожалуйста:

1. **НЕ создавайте публичный Issue** с описанием уязвимости
2. Отправьте email на [info@a2ya.ru](mailto:info@a2ya.ru)
3. Опишите уязвимость подробно:
   - Тип уязвимости (XSS, SQL Injection, CSRF и т.д.)
   - Шаги для воспроизведения
   - Потенциальное влияние
   - Предложения по исправлению (если есть)

Мы ответим в течение 48 часов и опубликуем исправление в течение 7 дней.

## Безопасность данных

Плагин:
- Не собирает персональные данные пользователей
- Не отправляет данные на внешние серверы
- Использует стандартные механизмы безопасности Redmine
- Не хранит пароли или токены

## Аудит кода

Код плагина открыт для аудита. Если вы хотите провести аудит безопасности:
1. Форкните репозиторий
2. Проведите анализ
3. Сообщите о найденных проблемах через email (см. выше)
