# Changelog

Все значимые изменения в проекте Redmine Hierarchy Sort будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.0] - 2026-07-31

### Изменено
- Полностью переделан алгоритм выборки задач по запросу с обходом дерева для оптимизации скорости выполнения скрипта. При показе 25 задач верхнего уровня время сократилось с 3 секунд в 10 раз.

---

## [1.0.0] - 2026-07-28

### Добавлено
- Иерархическая сортировка задач с сохранением древовидной структуры
- Два независимых блока фильтров: для корневых задач и для потомков
- Два независимых блока сортировки: для корневых задач и для потомков
- Пагинация по корневым задачам
- Рекурсивная загрузка потомков с применением фильтров
- Визуализация связей между задачами через иконки и всплывающие окна
- Поддержка обоих направлений связей (входящие/исходящие)
- Группировка связей по типам в popover
- Кликабельные номера связанных задач
- Русская и английская локализация
- Совместимость с Redmine 5.0+ и 6.0+
