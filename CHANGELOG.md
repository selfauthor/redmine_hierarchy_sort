# Changelog

Все значимые изменения в проекте Redmine Hierarchy Sort будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [2.0.5] - 2026-10-16

### Добавлено
- **Фильтрация по полям родителя**: В блок фильтров добавлена новая группа «Родительская задача». Теперь можно задавать условия отбора на основе атрибутов непосредственного родителя задачи (например, «Верх.: Статус» = «Открыт»).
- **Сортировка по полям родителя**: В критерии сортировки динамически добавляются виртуальные колонки с префиксом «Верх.: » для всех стандартных полей (статус, приоритет, даты, автор, исполнитель и т.д.) и пользовательских полей родительской задачи. Реализовано через эффективные коррелированные подзапросы.
- **CSS-хук для кастомизации**: При включении опции «Дерево подзадач» к таблице списка задач автоматически добавляется класс `hierarchy-sort`, что позволяет администраторам гибко настраивать визуальное отображение вложенных уровней через пользовательский CSS.
- **Документация**: Создано подробное «Руководство пользователя» (`USER_GUIDE.md`) с пошаговыми сценариями использования, а `README.md` структурирован для быстрого ознакомления.

### Изменено
- **Оптимизация `HierarchyBuilder`**: Алгоритм загрузки потомков переведен на пошаговое выполнение по уровням вложенности (level-by-level). Это значительно снижает нагрузку на базу данных и потребление памяти при глубоких иерархиях.
- **Условная предзагрузка (Conditional Preloading)**: Данные о связях (`relations`), затраченном времени (`spent_hours`) и последних комментариях теперь загружаются только в том случае, если они явно запрошены в настройках отображения запроса.
- **Совместимость**: Обновлена архитектура патчей (`QueryPatch`, `IssueQueryPatch`) для полной совместимости с Redmine 6.0 и Ruby 3.2 с использованием безопасных методов переопределения (`alias_method` и `define_method`).

### Исправлено
- Устранена ошибка 500 (Internal Server Error), возникавшая при отображении списка задач в определенных сценариях сложной фильтрации.
- Исправлены ошибки JavaScript при динамическом добавлении и переключении фильтров подзадач в интерфейсе.
- Корректная изоляция локализации: группа фильтров родительской задачи теперь использует отдельный ключ локализации (`label_parent_issue_filters`), что предотвращает нежелательное изменение названий в других частях интерфейса Redmine.

## [1.1.0] - 2026-07-31

### Добавлено
- Визуализация связей задач через всплывающие окна (popover) с группировкой по типам связей и индикацией направления (входящие, исходящие, двунаправленные).
- Независимые блоки фильтров и сортировки для подзадач.
- Поддержка межпроектных связей (потомки могут находиться в других проектах).

### Изменено
- Полностью переделан алгоритм выборки задач по запросу с обходом дерева для оптимизации скорости выполнения скрипта. При показе 25 задач верхнего уровня время сократилось с 3 секунд в 10 раз.
- Пагинация теперь применяется строго к корневым задачам, обеспечивая отображение полных веток на одной странице.
- Настройки плагина полностью интегрированы в хэш `options` модели `Query`, что гарантирует безопасное удаление плагина без повреждения существующих запросов Redmine.

### Исправлено
- Устранены конфликты при экспорте иерархических запросов в стандартные форматы Redmine.

## [1.0.0] - 2026-07-28

- Иерархическая сортировка задач с сохранением древовидной структуры
- Два независимых блока фильтров: для корневых задач и для потомков
- Два независимых блока сортировки: для корневых задач и для потомков

- Кликабельные номера связанных задач
- Русская и английская локализация
- Совместимость с Redmine 5.0+ и 6.0+
